Customer Segmentation & Revenue Analytics

Overview

Analyzed 500K+ online retail transactions to segment 4,300+ customers based on purchasing behavior using RFM analysis and K-Means clustering.

Methodology

Cleaned and preprocessed retail transaction data

Engineered Recency, Frequency, and Monetary (RFM) features

Standardized features using StandardScaler

Evaluated clusters using Elbow Method and Silhouette Score

Applied K-Means clustering to identify 4 customer segments

Used PCA for cluster visualization

Built an interactive Tableau dashboard for segment and revenue analysis


Customer Segments

Core / Regular

At Risk / Lapsed

Loyal / High-Value

Premium


Key Insights

Loyal and Premium customers (~5%) contribute ~48% of total revenue

Core customers contribute ~47% of total revenue

At-Risk customers (~25%) contribute only ~6% of revenue


Business Recommendations

Retain Premium customers through personalized benefits and loyalty rewards

Upsell and cross-sell to Loyal customers

Convert Core customers into Loyal customers through targeted offers

Reactivate At-Risk customers through personalized win-back campaigns
